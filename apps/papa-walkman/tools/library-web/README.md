# Kiro 音乐库测试页

本地只读测试，使用浏览器原生播放器；不安装依赖、不修改音乐服务器。

启动：`python3 tools/library-web/server.py`，打开 <http://127.0.0.1:8769>。

- 默认直连真实 JSON 接口，也可切换 M3U。
- 搜索、专辑和缺失字段筛选；选曲预览真实封面、同步／纯文本歌词。
- 点击「播放试听」验证实际音频，原生控件可跳转和调音量。
- 「检查当前歌曲」检查音频 Range、封面与歌词；全部检查只读取不同的封面／歌词资源，并发数为 3。
- 「本地代理」用于服务端数据可用但跨域尚未配置的情况。代理成功不表示 CORS 正常；通过「验证浏览器直连」单独检查。
- 导出 JSON 报告保留覆盖率、响应和检查结果，不包含完整歌词。

代理仅监听 127.0.0.1，仅允许 HTTPS 的 kiro.papaclaoud.top，不提供写操作。

验证：`node tools/library-web/core.test.mjs`。
