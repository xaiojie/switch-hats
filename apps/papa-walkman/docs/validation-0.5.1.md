# 0.5.1 页面统一与歌词滚动

日期：2026-10-30。针对用户最新四张真机截图，统一曲库、设置与播放页，并将定时歌词直接换字改为连续滚动。三套主题保留：唱片内页、夜航唱片、歌词剧场。

## 依据与根因

本次取得并查看的截图来自 `/sdmc:/emuMMC/SD00/Nintendo/Album/2026/10/30/`，保存在 `build/diagnostics/device-0.5.0/`，文件时间分别为 20:12:33、20:12:47、20:12:50、20:13:02。曲库与设置仍使用旧版宽标题、整排按钮和较重的面板结构，只有配色跟随新主题；播放页已经使用居中导航、留白与大封面。旧歌词按时间直接替换当前句及相邻句，没有连续位置状态。

同目录 log/trace 显示 0.5.0 进入主循环，JSON 来源解析 90 首可播放歌曲，实际加载封面及 73 行歌词，约 105 秒内取得 1557 帧、取帧失败 0。该记录没有最后的正常退出标记，不作为正常退出证明，也不证明新版动画的真机流畅度。

## 改动

- 所有页面统一「曲库／播放／设置」居中导航、字体、留白、主题颜色和轻量底部播放条。曲库改为左侧来源导航，歌曲／专辑／歌手与搜索位于内容上方，列表突出歌名，减少整排操作按钮。
- 设置分为「播放与外观、音乐源、存储与维护、歌单」四组，每次只显示当前组。三套主题直接点选；音量、模式、来源、缓存、刷新和歌单操作保留。手柄 ZL／ZR 切组，↑↓ 选择、A 执行，右摇杆继续切换主题。
- 同步歌词采用约 500ms 的 cubic-bezier(.22,1,.36,1) 上移过渡，当前句连续突出，相邻句淡出；三套播放布局与展开歌词页共用实现。过渡中再次换句从当前显示位置继续；相同时间戳的原文／译文跨多行也会滚动。
- 切歌、切页、换主题、改变歌词偏移、拖动进度或完成跳转时重新定位。暂停／缓冲不推算播放时间，已有过渡可有限结束；普通文本与缺失歌词保持对应提示。
- 文字限定在歌词区域内并淡化边缘，复用缓存字形，不按动画中间字号重复创建字形缓存；没有增加逐帧文件读取、网络请求或封面解码。只有活动过渡或位置变化请求额外重画，且绘制最终停止帧。
- 页面、设置分类及曲库来源／分组／搜索内容变化会取消旧触摸手势，避免按住后切布局误触。

主要文件：`source/ui.hpp`、`source/ui.cpp`、`source/ui_views.inc`、`source/ui_player.inc`、`source/ui_lyrics.inc`、`source/lyric_motion.hpp/.cpp`、`source/main.cpp`、`source/interaction.hpp/.cpp`，及对应测试和预览工具。`CMakeLists.txt` 两处版本与 `source/log.cpp` 同步为 **0.5.1**。
