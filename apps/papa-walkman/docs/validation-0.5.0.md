## 使用方式

设置页轻触「主题 · 当前主题」，或按下右摇杆，依次切换：

1. **唱片内页**：暖白底色，左侧大封面，右侧歌名与当前／相邻歌词。
2. **夜航唱片**：深色界面，封面与透明黑胶唱片组合，左右分别显示歌曲资料与歌词。
3. **歌词剧场**：奶油黄色，大字当前歌词，封面与歌曲资料在左侧，黑色播放按钮。

三个主入口、曲库、专辑、队列、歌词和设置均随主题配色。主要导航和收藏／队列按钮触摸区域至少 64 px；播放控制保留更大按钮。主播放页封面仍可轻触切换为磁带。

## 实现

- `Settings.theme` 保存稳定编号 0／1／2。旧配置或未知值默认唱片内页，保存沿用临时文件与备份恢复。
- 切换只更新主题、排队保存设置；不重启音频、不改变队列、不扫描曲库。后台保存保留最后一次主题选择。
- 绘制、点击和拖动共用 `PlayerLayout`。进度条最右侧可触像素对应 100%，越界拖动被限制在有效范围。
- 手指按住时若主题或页面改变，取消旧手势；等待松手后重新接受输入，防止新布局误触。
- 黑胶为原创透明 PNG，在渲染器初始化时仅解码一次。歌曲封面仍来自当前歌曲；字形与缩放图像继续缓存，没有为主题引入每帧文件读取或解码。
- 三套布局支持歌词换行、超长文字省略、普通歌词、缺失封面／歌词、缓冲和错误提示。原创街景图及虚构歌曲资料仅用于预览，不嵌入为真实歌曲封面。

主要改动文件：`source/core.hpp/.cpp`、`source/main.cpp`、`source/interaction.hpp/.cpp`、`source/ui.hpp/.cpp`、`source/ui_views.inc`、新增 `source/ui_player.inc`／`source/ui_vinyl.inc`、`assets/themes/vinyl.png`、`tools/preview.cpp`、对应 core／runtime／ui／interaction 测试，以及 `CMakeLists.txt` 和 `source/log.cpp` 版本信息。
