# Switch Link 0.2.1

**由我们自己的 Switch Link 主机端通过 HTTP 下载并安装游戏。** 网页发起任务，Switch Link 完成安装并回传真实结果；DBI 不是此功能的安装执行端。

## 使用

1. Switch 主机打开 **Switch Link 0.2.1** 并保持接收页面。旧0.1.1不支持本次HTTP安装，需要更新NRO；保留旧版作为回退。
2. 电脑双击 `Start Switch Link.cmd`，打开 `http://127.0.0.1:8088/#install`。选择发现的自己的 Switch Link 主机，无需反复输入IP。
3. 在网页选择 **安装包并安装**；也可以对已加入电脑游戏库的包直接点安装，不重复上传。
4. 数据经HTTP从电脑传到Switch Link，由其现有安装引擎安装到SD卡。保持接收页面，不在安装中退出。

同一局域网的手机或其他电脑也可打开 `http://运行服务的电脑IP:8088/`。本机仍可使用上面的 127.0.0.1 地址；启动信息及 `/api/status` 会给出当前实际局域网地址。

网页和主机显示实际安装步骤与进度，应用注册阶段可为不定进度。HTTP发送字节包括分段读取和重读，不能当作整体安装百分比。只有匹配本次任务且Result为0、已注册应用记录大于0的主机回执，才显示安装完成。

主机当前构建支持NSP、XCI；不宣称支持未启用的NSZ/XCZ。可将其他格式保存在电脑库中，但不能向不支持该格式的主机发起安装。

## 文件管理

网页 **FTP 文件管理** 保留SD卡浏览、上传下载、新建文件夹、改名、删除文件/空目录及覆盖备份。Switch Link的FTP服务用于文件操作，不再用FTP传输游戏安装数据。HTTP安装中不同时整理SD文件或切换主机。

## 服务与文件

- 管理网页8088默认监听本机和局域网（0.0.0.0）；LAN HTTP共享默认8080。需要只允许本机时使用 `python server.py --host 127.0.0.1`。
- 安装包库默认是仓库里的 `apps/switch-link/data/library`（`data/` 不入库），可用 `--library` 指定其它目录。
- 新包完整接收后原子加入库，同名文件拒绝替换；不自动删除原安装包。
- 已有兼容8080服务时不重启它，原下载继续；原生安装的能力URL必要时自动走8081，无需手输地址。
- 有效的一次性任务URL仅绑定指定主机和包；下载完成不是安装完成。UDP命令按任务编号去重，主机记住最后接收的任务避免重启后重复安装。
- 安装队列只保存在当前运行中，重启不会自动重装。正在执行的安装不可被网页当作普通上传随意取消，尚未发出的排队任务可取消。
- 进程自带HTTP共享时，不要在下载/安装中关闭或重启电脑服务。
- 不修改DBI、大气层、虚拟系统、钥匙或引导文件；新NRO使用独立目录部署。

## 验证

Python：`python -m unittest discover -s tests -v`。网页：static/ 下 `node --test *.test.cjs`。开发环境需要 pyftpdlib、Playwright/Edge；正常使用电脑端只需Python3.11标准库。console/ 保留GPL许可、对应源码和构建记录。

测试与编译通过不等于真机安装成功；完整安装和实际速度需要在主机打开新版后验证。此改动不自动恢复此前已经停止的测试任务。
