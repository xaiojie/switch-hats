发现你的 Switch

在主机打开 Switch Link 接收页面。选择主机后，网页即可发起 HTTP 安装或管理 SD 卡。

没有找到？保持主机应用在前台，并检查电脑与主机是否连接了同一个 Wi-Fi。访客网络可能会阻止设备相互连接。

连接只需要三步

  1. 01

    打开主机应用

    在 Switch 上打开 Switch Link 0.2.1 或更新版本，保持接收页面。

  2. 02

    连上同一个网络

    电脑和 Switch 使用同一 Wi-Fi 或有线局域网。

  3. 03

    选择你的主机

    点击「发现主机」，从搜索结果中选择即可。

游戏安装由网页发起，Switch Link 通过 HTTP 读取并安装。文件管理使用 FTP。安装中请保持 Switch Link 接收页面打开。
